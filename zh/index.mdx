# OpenClaw 文档总览

这个仓库不是单一路线文档，而是一套混合知识库。你可以把它理解成 4 条并行内容线：`动手学 Pi` 课程、当前的 `OpenClaw` 产品教程、保留中的 `Trellis` legacy 指南，以及 `AI 学习资料`。

## 动手学 Pi：从零实现一个 Coding Agent

沿 15 个可运行 checkpoint，从一条离线 Agent 轨迹开始，亲手实现一个 Pi-style coding agent。每章由四部分闭环：**教材正文 + 真实 commit + 聚焦测试 + 故障实验**。课程代码不是伪代码演示，而是一条可以 checkout、运行和验证的 Git 历史。

## 这三条内容线现在分别是什么

| 内容线 | 当前状态 | 最适合谁 |
| --- | --- | --- |
| 动手学 Pi | 社区原创的编码 Agent 课程 | 想亲手实现 Agent 内核、理解模型与工具闭环的读者 |
| OpenClaw | 当前维护中的主线 | 想部署个人 AI 助手的读者 |
| Trellis legacy | 保留中的历史文档 | 想查旧工作流、旧设计和历史背景的读者 |
| AI 学习资料 | 归档型资料区 | 想系统补基础、翻资料和继续整理旧内容的读者 |

## 推荐阅读路径

1. 如果你想亲手实现一个 coding agent 的内核，从 [动手学 Pi 序章](/zh/pi-textbook/prologue) 开始。
2. 如果你想真正搭一个 AI 助手，直接进入 [OpenClaw 总览](/openclaw/index)。
3. 如果你在维护或研究旧的 Trellis 工作流，先看 [什么是 Trellis](/guide/ch01-what-is-trellis)。
4. 如果你只是想系统补 AI 基础，先看 [AI 学习资料](/ml/index)。
